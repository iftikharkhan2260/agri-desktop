Put your app icons here before running `npm run dist`:
- icon.ico  (Windows, 256x256 multi-size .ico)
- icon.icns (Mac)
- icon.png  (Linux, 512x512 recommended)

Free tool to generate all three from one PNG: https://icoconvert.com
If these files are missing, electron-builder uses its own default icon —
the build still works, it just won't have your shop's branding on it.
